# 💪 온라인 PT · Online Personal Training

브라우저만으로 동작하는 **온라인 퍼스널 트레이닝** SPA입니다. 트레이너를 찾아 이용권을 구매하고,
시간대를 예약한 뒤, **모의 화상 세션 룸**에서 타이머와 오늘의 루틴 체크리스트·자세 피드백 메모로
1:1 홈트를 진행하고, 진행상황을 기록합니다. 빌드·백엔드·계정 없이 즉시 실행됩니다.

**🔗 라이브 데모: https://clsoftlab-lang.github.io/online-pt/**

> Read this in English: **[README.md](README.md)**

## 무엇인가요

"집에서 화상으로 1:1 PT를 받는다"는 아이디어를, 클릭 가능한 완성형 데모로 구현했습니다.
가상 트레이너 14명을 탐색·필터·정렬하고, 프로필과 리뷰를 보고, **모의 결제**로 이용권을 구매(횟수 충전),
캘린더에서 시간대를 골라 예약하면 **횟수가 1회 차감**되며, **모의 화상 세션 룸**에 입장해 루틴을 수행한 뒤,
출석·운동 시간이 진행상황 그래프에 쌓입니다.

## 기능

- **트레이너 탐색** — 전문분야·성별·가격·평점 필터 + 검색, 평점/리뷰/가격/경력 정렬.
- **트레이너 상세** — 소개·자격·예약 가능 시간대 미리보기·리뷰·가격.
- **PT 이용권** — 1/4/12/24회권 4종. **모의 결제** 즉시 횟수 충전.
- **예약** — 트레이너 실제 가용 요일 기준 14일 캘린더. 시간 선택 시 **1회 차감** + 같은 시간 중복 예약 방지.
- **화상 PT 세션 룸(모의)** — 트레이너·나 SVG 카메라 타일, **작동하는 타이머**, 세트·횟수·휴식·코칭 큐가 담긴 **루틴 체크리스트**, **자세 피드백 메모**.
- **운동 프로그램/루틴** — 목표별 6종(지방연소·근력·자세교정·코어·시니어·바디프로필), 세트/횟수/휴식 + 동작 아이콘.
- **내 진행상황** — 완료/예정 세션, 남은 횟수, 총 운동 시간, 주간 출석 막대그래프, 스트릭, 운동 기록.
- **리뷰 작성** — 트레이너별 평점 + 후기.
- **부가 기능** — 체형/목표 **설문 → 추천 트레이너**(점수·사유 표시), **세션 후 요약**(시간·달성률·만족도·코치 메모).
- 예약 취소 시 **횟수 환불**. **라이트+다크** 테마, **모바일 우선** 반응형 한국어 UI.

## 핵심 로직

도메인 로직은 DOM 비의존 [`pt-engine.js`](pt-engine.js)에 있고 [`check.mjs`](check.mjs)에서 단위 테스트됩니다.

- **구매** → `purchasePass()`가 `remaining = sessions`인 이용권 생성.
- **차감** → `consumeCredit()`가 남은 횟수가 있는 **가장 오래된** 이용권에서 1회 차감, 없으면 예외.
- **예약** → `createBooking()`이 `hasConflict()`(같은 날짜+시간) 검사 후 1회 차감하고 확정 예약 추가. 취소 시 `refundCredit()`로 환불(플랜 총량 초과 방지).
- **세션 종료** → 기록 저장 + 예약 `completed` 처리, `computeProgress()`가 출석/시간/주간/스트릭 집계.
- **추천** → `recommendTrainers()`가 전문분야·선호성별·관심부위·예산 + 평점/경력 품질 가중으로 점수화 후 내림차순 정렬.

## 로컬 실행

의존성·빌드 없음. ES 모듈은 `file://`이 아닌 `http://`가 필요하므로 정적 서버로 엽니다.

```bash
python -m http.server 8983
# http://localhost:8983 접속
```

검증(JSON 파싱 + 모든 JS `node --check` + 필수 컨테이너 + 엔진 단위 테스트):

```bash
node check.mjs
```

## 데모 모드 경계 (중요)

- **화상 통화는 시뮬레이션 UI일 뿐입니다** — SVG 카메라 타일 + 타이머. **실제 웹캠·WebRTC·라이브 영상 없음**, 카메라 접근 없음.
- **트레이너·리뷰·가격·루틴은 모두 가상 시드 데이터**(`data/*.json`)입니다.
- **저장은 브라우저의 `localStorage`이며 실제 DB가 아닙니다** — 기기를 벗어나지 않고 ↺ 초기화 버튼으로 삭제됩니다.
- **실제 결제 없음** — 결제는 모의이며 아무 금액도 청구되지 않습니다.
- **실제 계정·로그인·개인정보(PII) 수집 없음.**
- **실제 서비스라면 추가될 것:** 백엔드+DB, 실제 **WebRTC** 화상, 결제 게이트웨이, 인증, 트레이너 온보딩/스케줄링, 알림.

## 기술

프레임워크·번들러 없는 순수 **HTML + CSS + ES 모듈 JS**. 모든 아트는 인라인 **SVG**.
`fetch`로 `data/*.json` 로드, 상태는 `localStorage`에 저장(try/catch + 인메모리 폴백).
GitHub Actions에서 Node 20으로 `node check.mjs` 실행.

## 🤖 AI 기능 (API 연동)

앱에는 **교체 가능한 AI 레이어**가 포함되어 있으며, 세 가지 기능 모두 **일반적인 운동 가이드이며 의학적 조언이 아님**을 명시합니다.

1. **AI 운동 코치 챗봇** — 목표·부상 입력 → 조언 + 어울리는 트레이너 추천.
2. **목표 → 맞춤 루틴 생성** — 목표/수준/가용 시간으로 운동 루틴 생성.
3. **세션 요약/피드백 생성** — 세션 종료 요약 창에서 요약 + 코치 피드백.

**데모 모드 = mock (서버·키 불필요).** `ai/config.js` 의 `AI_ENDPOINT = ""` 이면 `askAI(task, payload)` 가
앱의 트레이너/루틴 데이터를 재사용하는 **결정론적 한국어 MockProvider** 로 동작합니다 — AI 탭이 바로 작동합니다.

**실제 Claude 연동**은 백엔드 프록시를 실행하고 프론트가 이를 가리키게 하면 됩니다.

```bash
cd server && npm install && cp .env.example .env   # .env 에 키 입력 후:
npm start                                           # http://localhost:8790
```

그리고 `ai/config.js` 를 설정:

```js
export const AI_ENDPOINT = "http://localhost:8790/api/ai";
```

프록시([`server/index.mjs`](server/index.mjs))가 `@anthropic-ai/sdk` 로 Claude(모델 **`claude-opus-5`**)를
`process.env.ANTHROPIC_API_KEY` 로 호출하고 응답을 스트리밍합니다.

> **🔐 키는 오직 서버에만 둡니다.** API 키는 백엔드(`ANTHROPIC_API_KEY`)에만 존재하며,
> **브라우저·프론트 코드·리포지토리에는 절대 두지 않습니다.** 프론트는 `{ task, payload }` 만 `AI_ENDPOINT` 로 보낼 뿐 키를 알지 못합니다.
> CI 는 `node check.mjs`(=`AI_ENDPOINT` 가 비었는지 + 실제 키 형식이 없는지 검사)만 실행하며,
> 의존성 설치·서버 실행·실제 API 호출은 하지 않습니다.

자세한 내용은 [`server/README.md`](server/README.md) 참고.
